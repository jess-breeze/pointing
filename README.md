# pointing

Analysis code for Breeze, Lu, Levan, Lillo-Martin and Goldin-Meadow, *Children can
override the gestural models they see to create a linguistic system*.

Each analysis is an R Markdown file with its knitted HTML report alongside.

## Study 1: English-learners, ASL-learners and homesigners

| File                                                      | Contents                                                                                                                                                                                               |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `study1_three_groups/study1_descriptives_and_figures.Rmd` | Table 1, Figures 1 to 3, Table S2, Figures S1 to S3                                                                                                                                                    |
| `study1_three_groups/study1_duration_models.Rmd`          | All duration models: all points, points produced alone, points produced with other acts, semantic controls, isolation by group, robustness checks; Tables S3 and S4, Figure S4, convergence (Table S9) |
| `study1_three_groups/study1_reliability.Rmd`              | Agreement and Cohen's kappa for semantic-role coding                                                                                                                                                   |
| `study1_three_groups/figures/`                            | Figures 1 to 3 and S1 to S3, as written by the descriptives report                                                                                                                                     |

## Data availability

Individual-level coded data (pointing durations, semantic role classifications, and
utterance types) cannot be shared publicly because the IRB
protocols under which the data were originally collected do not permit release without a
data use agreement. Researchers seeking access to the individual-level data for purposes
of reproducing or extending the analyses may contact the corresponding author.
